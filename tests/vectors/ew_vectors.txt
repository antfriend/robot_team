# Read by tests/test_ew.cpp (ttdbParseEw, firmware/libraries/TTDB) AND tests/test_ew_py.py
# (fleet.parse_ew). TTDB-RFC-0010 §7.2's lesson: test the PAIR, not each side — the two
# readers are only known to agree on the inputs listed here, so a new rule goes in this
# file, never in one test.
#
# Rules: TTDB-RFC-0005 §3.1, §4.1-§4.3; `prec` from TTDB-RFC-0011 §3.1 (stage 1, readers).
#
# Format (line-oriented, no escapes):
#   === <name> [crlf]     starts a case. Every following line up to `--- expect` is the
#                         record text, joined with "\n" (or "\r\n" if `crlf`) and ending
#                         with one newline unless the case is flagged `noeol`.
#   --- expect k:v ...    the parsed result. ALL eleven keys are required, so no case can
#                         quietly stop checking a field: present conf rev sal touched prec
#                         has_conf has_rev has_sal has_touched has_prec
# Lines starting with '#' are comments only OUTSIDE a case.
# ⚠ This file is pinned eol=lf in .gitattributes: on a CRLF checkout every case would
# silently become a CRLF case, and the `crlf` flag would test nothing.
